# test1 보고서 — 실도면 → 파라메트릭 CAD 파이프라인 테스트 (1차)

## 1. 테스트 개요

- 목적: 2D 도면 이미지 입력 → 질문(Q&A) → FreeCAD 파라메트릭 모델(.fcstd) 생성 파이프라인의 첫 실전 테스트.
  단순 형상이 아니라 복잡한 도면으로 검증 (사용자 요구: 단순한 테스트는 의미가 없고, 복잡한 도면에서 검증해야 함).
- 입력: 실도면 이미지 1장 (사용자 제공). 보안상 원본 도면 이미지는 본 보고서, zip, GitHub 업로드 어디에도 포함하지 않음.
- 출력: 최종 모델 real_drawing_gear_v5.fcstd (+ STEP), TechDraw 2D 도면 (PDF/SVG), 본 보고서, test1_results.zip.
- 도구: FreeCAD 1.1.4 (AppImage), PartDesign (InvoluteGear, Pad, Pocket, Chamfer), verify_model.py 검증 하네스.
- 기간: 2026-10-27 (당일).

## 2. 최종 모델 사양 (v5, 확정)

- 단품, 외접 스퍼 기어.
- 기어: 모듈 0.5, 30T, 압력각 20°, 인벌류트 (PartDesign InvoluteGear). 끝 16.001 / 피치 15.0 / 루트 13.750 (표준).
- 축 방향: 기어 5 + 단차 1 + 몸통 7 = 전체 13.
- 몸통 φ22, 한쪽 면 평면 1mm 절단 (높이 21, 직사각형 평면 9.165×7).
- 단차 φ16 (치형 끝과 동일).
- 중심 보어 φ7.93 관통, 리머가공.
- 나사홀 3곳: 탭드릴 φ3.73 + 11/64″-40 탭가공, 평면 중앙(270°) 기준 120° 간격(30°/150°), 몸통 중간 높이, 외경→보어까지만.
- 모따기: 보어 앞뒤 C0.5 (2곳).
- 일반공차 ±0.1.
- 체적: 2821.577 mm³, 단일 유효 솔리드.
- 피처 트리: InvoluteGear → Pad_Gear → Sketch_Step → Pad_Step → Sketch_Body → Pad_Body → FlatCut → Sketch_Bore → Pocket_Bore → TapDrillHole_1/2/3 → Chamfer_Outer.

## 3. 검증 결과

- verify_model.py: OVERALL PASS (스케치 닫힌 와이어, 피처별 유효 솔리드 + 체적 > 0, 단일 솔리드).
- per-step 게이트: 각 피처 생성 시마다 검증, 실패한 단계만 재생성 (전체 재생성 없음).
- 모델-vs-도면 대조: v5 모델에서 TechDraw HLR 투영(콘솔 모드)으로 정면/측면/평면 투영 도면을 생성해 확보 (PDF/PNG, 치수 기입은 미포함, 후속 작업).
  참고: TechDraw Page(도면 페이지) 내보내기는 헤드리스 GUI 모드에서 동작하지 않아 (Page 타입 미등록 + GUI 행) 콘솔 HLR 투영(project 함수)으로 우회함.

## 4. 테스트 이력 (시행착오 기록) — v1 → v5

- v1: 내접기어로 잘못 해석. 정면도에서 기어(16)가 몸통(22) 안에 보여서 내접으로 읽음.
  몸통 22×7 + 림 18 + 치형(루트 16/끝 12) + 보어 7.93 + 나사홀 φ4.37(외경 기준) + 모따기. 체적 2384.046.
  교훈: 도면의 원 안에 있는 치형이 내접이라는 뜻은 아님, 방향은 별도 확인 필요.
- v2: 사용자 교정 반영. 축 7+1+5=13, 평면 기준 나사홀 각도(270°/30°/150°), 평면 직사각형 확인,
  뷰 퍼즐 해결 (하면 원 = 평면 중앙 홀 등). 단차 20 (추정). 체적 2669.623.
- v3: 사용자 교정. 단차 16 (20 아님), 나사홀을 외경이 아닌 탭드릴 φ3.73 + 탭가공으로 변경.
  11/64″-40은 비표준 나사라 표에 없음. 탭드릴 = 외경 − 피치 = 4.366 − 0.635 = 3.731 → 3.73,
  #26 드릴 3.734 근접, 기본 내경 3.68보다 커서 탭 파손 없음.
  FreeCAD Hole(탭) 기능은 커스텀 나사 미지원으로 사용 불가 (표준 사이즈로 되돌림 확인).
  평면 완전 직사각형 (53.229). 체적 2640.321.
- v4: 사용자 교정. 치형 방향 수정 (내접 → 외접). 루트 디스크 12 + 치형이 바깥으로 16까지.
  단차 16이 치형 끝과 일치. 보어 전체 13 관통. 체적 2682.592.
  "18" 치수 매핑 해제 (림이 없어짐).
- v5: 사용자 교정. 사다리꼴 치형을 표준 인벌류트 기어 도구(InvoluteGear)로 교체.
  모듈 0.5 (16/(30+2)), 30T, 20°. 끝 16.001 / 루트 13.750 / 피치 15.0. 체적 2821.577.
  교훈: 표준 부품은 표준 도구부터 (수작업 근사 금지).

## 5. 파이프라인에서 얻은 교훈 (시행착오 축소 방안)

- 도면 해독표 선행: 빌드 전 모든 치수/지시를 피처에 매핑 + 확신도 표기, 사용자 확인 후 빌드
  (2026-10-27 합의, 본 테스트의 남은 미확인 항목에 첫 적용 — inputs/real-drawing/reading_sheet.md 참조).
- 표준 부품 표준 도구: 기어 → InvoluteGear, 나사 → 탭드릴 + 탭 (Hole 기능의 커스텀 나사 한계 확인).
- 모델-vs-도면 대조 게이트: 빌드 후 정면/측면/평면 투영을 도면 뷰와 비교.
- 헤드리스 2D 도면: TechDraw Page는 GUI 모드에서만 동작하므로, 헤드리스에서는 TechDraw project 함수(HLR)로 투영 후 렌더링하는 경로를 쓸 것.
- 버전별 파일 + 피처별 게이트 + STEP 명암 렌더 유지 (시행착오를 싸게 만든 장치).

## 6. 미확인 항목 — 사용자 답변으로 종결 (2026-10-27)

도면 해독표(reading_sheet.md)의 Q1~Q5에 대한 사용자 답변으로 아래 항목은 모두 종결됨. v6 추가 작업 없음, v5가 최종 모델.

- Q1 측면 18: 무시 (모델링하지 않음).
- Q2 측면 12 / 기어 루트: 무시 (루트는 표준 인벌류트 13.75 유지, 12로 변경하지 않음).
- Q3 하면 중앙 탭(10): 무시 (해당 부분 미구현, 도면에 치수가 제대로 표현되어 있지 않음).
- Q4 1.5 (2곳): 무시 (정확한 표시가 없음).
- Q5 4-C0.5: 표기 오류, 2곳이 맞음. v5의 보어 앞뒤 C0.5 2곳이 전부이며, 추가 모따기 없음.
